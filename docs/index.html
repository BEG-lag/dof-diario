      Usa los datos

      Un archivo por día

      JSON normalizado con cada nota, su dependencia, página y liga oficial.

      curl -s https://raw.githubusercontent.com/BEG-lag/dof-diario/main/data/2026/11/2026-11-13.json

      Esquema documentado

      Cada archivo cumple el JSON Schema y se valida en cada actualización.

      schema/day.schema.json
data/YYYY/MM/YYYY-MM-DD.json
data/meta.json

      Para agentes de IA

      El servidor mcp-dof da a Claude el texto completo de cada nota.

      claude mcp add dof -- uvx --from \
  git+https://github.com/BEG-lag/mcp-dof mcp-dof

      No oficial: solo el DOF impreso/oficial es fuente auténtica; no constituye asesoría legal.

      Datos obtenidos de la API pública de SIDOF (Secretaría de Gobernación). Proyecto independiente, sin afiliación con el DOF. Código y datos en GitHub.
